## 📖 عن المشروع

**ذاكر** هو بوت تيليجرام ذكي مصمم خصيصاً للطلاب الجامعيين، وخاصة طلاب **كلية الحاسبات والذكاء الاصطناعي**.

بيساعد الطالب يفهم المحاضرات الإنجليزية، يلخص المحتوى، ويعمل كويزات تفاعلية — كل ده بالعربي!

---

## ✨ المميزات

### 📄 تحليل PDF المحاضرات
- 📝 **ملخص سريع** (5-7 نقاط)
- 📚 **شرح تفصيلي** (كل نقطة بالتفصيل + أمثلة)
- 🔤 **قائمة المصطلحات** (إنجليزي → عربي)
- 🎯 **كويز تفاعلي** (أسئلة على المحتوى)
- 💡 **أمثلة عملية** (من الحياة الواقعية)
- 🧮 **تمارين ومسائل** (بالحل خطوة بخطوة)

### 🌍 ترجمة وتلخيص النصوص
- ترجمة فورية للإنجليزية
- تلخيص ذكي بالعربي
- دعم كامل للمحتوى العربي

### 🎮 نظام Gamification
- 💎 **نظام النقاط (XP)** — اكسب نقاط مع كل استخدام
- 🏆 **6 مستويات** — من "مبتدئ" لـ "أسطورة"
- 🎁 **هدية يومية** — نقاط مجانية كل 24 ساعة
- 🔥 **سلسلة الأيام** — مكافآت إضافية للاستمرارية
- 🥇 **لوحة المتصدرين** — تنافس مع أصحابك
- 👥 **دعوة الأصدقاء** — اكسب نقاط لدعوة أصحابك

### 🔐 حساب مميز
- 👑 **حساب Admin** للمطور
- 📊 **لوحة تحكم** بالإحصائيات
- ⭐ **باقات Premium** (قريباً)

## 🔧 التثبيت والتشغيل

### المتطلبات:
- Python 3.11+
- حساب Telegram Bot
- مفتاح Google Gemini API

### الخطوات:

```bash
# 1. Clone the repository
git clone https://github.com/mahmoud-nasef-dev/zaker-bot.git
cd zaker-bot

# 2. Install dependencies
pip install -r requirements.txt

# 3. Create .env file
echo "GEMINI_API_KEY=your_key_here" > .env
echo "TELEGRAM_BOT_TOKEN=your_token_here" >> .env

# 4. Run the bot
python bot.py
